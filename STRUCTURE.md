# Project structure

- `Sources/ClaudeUsage/main.swift` — app source.
- `Sources/ClaudeUsage/AppIcon.icon` — layered Icon Composer source.
- `ClaudeUsage.xcodeproj` — Xcode project and shared scheme.
- `Design/PreviousAppIcon` — earlier icon source retained for reference.
- `build.sh` — release build script.

Generated `build/` and `ClaudeUsage.app/` are ignored by Git.
